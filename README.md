## 🚀 Começando

1. **Site online:** https://atilahmh.github.io/norskproven-b1b2/
2. **Clonar localmente:**
   ```bash
   git clone https://github.com/atilaHMH/norskproven-b1b2.git
   cd norskproven-b1b2
   open index.html
   ```
3. **Anki:** importe `vocabulario/2000-palavras-core.csv`
4. **Cronograma:** siga `cronograma-12-semanas.md`

## 🧠 Método (resumo)

| Princípio | Aplicação |
|---|---|
| Active Recall | Flashcards Anki (20 min/dia) |
| Spaced Repetition | Revisões 1d → 3d → 7d → 21d |
| Comprehensible Input | NRK Super, Klar Tale (1h/dia) |
| Output forçado | 1 texto + shadowing diários |
| Feynman | Explicar regras em norueguês simples |
| Pareto 80/20 | 2000 palavras + 20 regras = 80% do exame |

## 📊 As 4 competências

| Competência | Tempo | Foco |
|---|---|---|
| 📖 Leseforståelse | ~60 min | Inferência, vocab acadêmico |
| 🎧 Lytteforståelse | ~35 min | Dialetos, NRK, detalhes |
| ✍️ Skriftlig | ~90 min | E-mail formal + argumentação 250+ palavras |
| 🗣️ Muntlig | ~20-30 min | Apresentação + discussão em dupla |
